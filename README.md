# StockAnalysis_MySelf

Nick 持股組合的「台股每日個股觀察報告」—— 每個交易日收盤後產出一份 mobile-first RWD 的單一自足 HTML，
發布在 GitHub Pages（分支 `gh-page`）。

## 檔案

| 檔案 | 說明 |
|---|---|
| [`報告守則.md`](報告守則.md) | **唯一權威規格**：資料來源、指標公式、五面向權重、雙情境建議、版面規格、存檔順序、交付檢查 |
| [`報告樣式.css`](報告樣式.css) | 完整樣式表，產生報告時整段內嵌到 `<style>`（單一自足，不可外連） |
| [`tools/`](tools/README.md) | 參數化產生器。只改 `config.py` 與 `inputs/*.py`，其餘程式不用動 |
| `建立Commit.bat` | 建立 commit（未版控）。push 由使用者自行決定時機 |
| `YYYYMMDD/index.html` | 每期報告（YYYYMMDD ＝ 資料基準日） |
| `index.html` | 總覽首頁，由 `tools/finalize.py` 重建 |

## 與 StockAnalysis 的區別

隔壁的 `StockAnalysis` repo 追蹤另一組 8 檔（6548／8070／8422／6411／5371／1717／4763／2231），
兩者共用同一份規格與版型，但**標的、repo 路徑與 remote 都不同，不要互相寫入**。
同一天兩組報告的**大盤環境分應該一致**，若不同則其中一份算錯了。

## 免責

本 repo 內容由自動化流程彙整公開資訊產生，僅供研究與教育參考，不構成投資建議。
所有評分為依既定公式計算之相對參考值，不代表對個股未來表現之預測。投資有風險，過去績效不代表未來表現。
